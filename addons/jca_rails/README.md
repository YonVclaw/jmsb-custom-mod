# JCA Rails

`jmfsb_jca_rails`

JCA's attachments on the base game's rails - the MX family and the SPAR-16/16S/17
(user, 2026-08-28: "look up all the JCA attachments and edit them to be
compatible with MXs and SPARs").

A rifle's slots are root classes, and an item fits a slot when that class's
`compatibleItems` lists it. **Which root class a rifle reads is not the same for
the two families**, and that is the whole story of why the dual mount did not
fit (cba_jr 3.19.0.260808 and the base game's weapons_f, derapified 2026-08-29):

| rifle | side rail | optic | under | muzzle |
|---|---|---|---|---|
| SPAR-16 / 16S / 17 | `asdg_FrontSideRail` (CBA JR) | `asdg_OpticRail1913` | `asdg_UnderSlot` | `asdg_MuzzleSlot_556` / `_762` |
| MX / MXC / MXM / MX SW / MX GL | **`PointerSlot_Rail` - vanilla's own; CBA JR never touches the MX's PointerSlot** | `asdg_OpticRail1913` | `asdg_UnderSlot` (MX, MXM, SW) | `asdg_MuzzleSlot_65`, which inherits every 7.62 can |

JCA lists its laser modules and torches on both root rails itself and keeps the
**dual mount** for its own M4A4. This addon adds the dual mount - every MRT
switch state of it, since the mount *becomes* `_Laser_Red`, `_Light` and so on
when switched - to the same two root classes, its bipods to `asdg_UnderSlot`,
its SR25 and AWM cans to the 7.62 and .338 slots, and its 5.56 rifle cans to the
MX's 6.5 slot. No weapon class is touched; JCA is untouched; without JCA or CBA
the addon skips itself.

**Two mistakes this addon has already made, so they are not made again.**
Patching `arifle_MX_Base_F`'s `WeaponSlotsInfo` for the pointer wrote the nested
classes without inheritance and replaced the MX's whole slot table. And writing
`class compatibleItems {` on `asdg_MuzzleSlot_65` - whose list CBA declares as
`class compatibleItems: compatibleItems` so the 6.5 slot inherits the 7.62 cans -
dropped that inheritance (the RPT says `Updating base class
'compatibleItems'->''`), and the MX lost every 7.62 suppressor. The generator
now knows which slots inherit their list.

Generated by `tools/gen_jca_rails.py` from the unpacked JCA config in
`D:\work\weapons_f_JCA_IA` - re-run rather than hand-edit (`--report` prints
what would be added).
